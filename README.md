# Water Habit Tracker

Aplicacion web simple para seguimiento de habitos de hidratacion.

## Stack

- Next.js 15 con App Router
- Supabase para Postgres y Auth
- Vercel para deploy
- TypeScript estricto
- Tailwind CSS
